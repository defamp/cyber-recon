# Security policy

## Authorized use only

This tool performs passive reconnaissance by default. It is intended for:
- Authorized bug bounty programs
- Vulnerability Disclosure Programs (VDP)
- Penetration tests with written permission

## Out of scope

- Any system you do not own or have explicit written permission to test
- Government, healthcare, or critical infrastructure without authorization
- Mass scanning of the public internet

## Active scanning

Active probing (nuclei templates, directory brute-force) is **opt-in**.
Enable only after confirming scope and rules-of-engagement with the program owner.

## Responsible disclosure

If you find a vulnerability, follow the program's disclosure policy.
Do not publicly disclose until the program owner grants permission.
